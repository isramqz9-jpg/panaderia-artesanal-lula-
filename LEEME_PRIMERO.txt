LULA — PÁGINA WEB
=================

QUÉ VIENE EN ESTA CARPETA
- index.html: la estructura y el contenido de la página.
- styles.css: los colores, tamaños y el diseño adaptable.
- app.js: el catálogo, buscador, filtros, favoritos, carrito y pedidos.

IMPORTANTE ANTES DE USARLA CON CLIENTES
Esta primera versión trae productos, precios e imágenes de ejemplo. Sustitúyelos por los productos reales de LULA. El pedido por WhatsApp necesita que configures el número comercial.

CÓMO ABRIRLA (MÉTODO SENCILLO)
1. Extrae la carpeta LULA_Web del ZIP si descargaste el ZIP.
2. No separes los tres archivos: index.html, styles.css y app.js deben quedarse juntos en la misma carpeta.
3. Haz doble clic en index.html. Se abrirá en tu navegador.
4. Necesitas conexión a Internet para que carguen las fotos externas y las fuentes. La página y sus funciones básicas están en tus archivos.

RECOMENDADO: USAR VISUAL STUDIO CODE + LIVE SERVER
1. Instala Visual Studio Code desde https://code.visualstudio.com/
2. Abre Visual Studio Code.
3. Ve a Archivo > Abrir carpeta y selecciona la carpeta LULA_Web.
4. En el panel izquierdo verás index.html, styles.css y app.js.
5. En Extensiones, busca e instala “Live Server” (publicador: Ritwick Dey).
6. Abre index.html y pulsa “Go Live” en la esquina inferior derecha. Se abrirá tu web en el navegador.
7. Cada vez que guardes cambios con Ctrl+S, actualiza el navegador si hace falta.

CÓMO CONFIGURAR WHATSAPP
1. En Visual Studio Code abre app.js.
2. Cerca del principio busca: whatsapp: "",
3. Escribe el número comercial entre las comillas, con código de país y solo dígitos. Ejemplo FICTICIO de formato mexicano: whatsapp: "521234567890",
4. No uses espacios, +, paréntesis ni guiones dentro del número.
5. Guarda con Ctrl+S y prueba hacer un pedido. El mensaje se prepara, pero la persona debe revisar y enviar el mensaje desde WhatsApp.

CÓMO CAMBIAR PRODUCTOS Y PRECIOS
1. En app.js busca la sección “const PRODUCTS = [”.
2. Cada producto tiene id, name (nombre), category (categoría), price (precio en pesos), description (descripción), badge (etiqueta) e image (URL de la foto).
3. Cambia los valores entre comillas y el precio numérico. No pongas el signo $ en price.
4. Conserva el formato y las comas entre productos. Haz una copia de app.js antes de editar si tienes dudas.
5. Las categorías se crean automáticamente según los productos que pongas.

CÓMO PONER FOTOS PROPIAS
- En cada producto, cambia el valor de image por la dirección de una foto pública, o coloca una imagen dentro de la carpeta y usa una ruta relativa, por ejemplo: "productos/concha.jpg".
- Si usas una ruta local, crea la carpeta productos dentro de LULA_Web y coloca ahí la foto.
- También puedes reemplazar las imágenes grandes de index.html buscando la etiqueta <img src="..."> correspondiente.

QUÉ FUNCIONA
- Diseño adaptable a móvil y computadora.
- Menú móvil, buscador y filtros por categoría.
- Favoritos que se guardan en ese navegador.
- Carrito con cantidades y total estimado.
- Formulario básico de pedido y mensaje preparado para WhatsApp.
- Validación sencilla del nombre y del teléfono opcional.
- Tema claro/oscuro, galería y enlaces a Instagram.

QUÉ DEBES CONFIGURAR O CONFIRMAR
- Número de WhatsApp real de LULA.
- Nombres, precios, descripciones y fotos del menú real.
- Ubicación, horarios, entregas, políticas y otros datos comerciales, si deseas mostrarlos. No inventamos esos datos porque no se han confirmado.
- Para que otros la vean por Internet necesitas publicarla en un servicio de hosting. Abrir index.html en tu computadora no la publica automáticamente.

NOTA SOBRE FUNCIONALIDAD
El sitio es funcional como página local, catálogo y preparación de pedidos. WhatsApp no envía automáticamente el mensaje: abre una conversación y el cliente debe pulsar Enviar. El pago en línea, inventario sincronizado y gestión real de pedidos requieren integrar servicios externos y no están incluidos en esta versión.
